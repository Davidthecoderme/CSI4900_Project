
# Welcome to ChatAI Assistant 🎉

This repository contains the complete implementation of our ChatAI-powered mobile health assistant. The project is structured into multiple folders for clarity and modular development.

## Project Structure

- `api-server/` - Backend API powered by FastAPI.
- `mobile-app/` - Frontend mobile application developed using React Native and Expo.

---

## Getting Started

### Backend Setup

To access the ChatAI Assistant API, navigate to the `api-server` directory and follow the setup instructions in its own `README.md` file. This will guide you through environment configuration, dependency installation, and how to start the API server.

```bash
cd api-server
# Follow instructions in api-server/README.md

```


### Frontend Setup
Once the backend is up and running, head over to the mobile-app folder. This contains our React Native frontend. Follow the setup instructions there to get the mobile application running on your iOS or Android emulator or device.

cd mobile-app
# Follow instructions in mobile-app/README.md
